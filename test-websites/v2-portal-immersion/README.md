# Version 2: Portal Immersion 🌐

## Design-Konzept
3D-First Dark Mode mit Glassmorphism und immersiver Experience

## Farbpalette
- **Primary:** Indigo #4F46E5
- **Accent:** Cyan #06B6D4
- **Background:** Dark #0F172A

## Features
✅ Modal Lightbox Video (Cinematic Click-to-Expand)
✅ 3D Globe Simulation (CSS Animations)
✅ Animated Portal Points mit Pulse-Effekt
✅ Glassmorphic UI Elements (backdrop-filter)
✅ 3D Hover Cards (Flip Animation)
✅ Dark Theme optimiert
✅ Gradient Typography
✅ Smooth Modal Transitions
✅ Responsive & Accessible

## Video Setup
**Wichtig:** Platzieren Sie Ihr Video hier:
```
./videos/prevideo-culturestream.mp4
```

Das Video öffnet sich in einem cinematic Modal beim Klick auf den "Portal in Aktion" Button.

## Special Features
- **3D Globe:** Drei rotierende Ringe mit Portal-Punkten
- **Portal Points:** Interaktive Punkte mit Pulse-Animation und Tooltip
- **Modal Video:** Fullscreen-ähnliches Erlebnis mit Backdrop Blur
- **Team Cards:** 3D Flip-Effekt beim Hover
- **Glassmorphism:** Subtil eingesetzt für moderne UI
