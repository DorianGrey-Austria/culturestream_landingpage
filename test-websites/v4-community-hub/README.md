# Version 4: Community Hub 🤝

## Design-Konzept
Warm Organic Design mit Community-Fokus und Sticky Video Player

## Farbpalette
- **Primary:** Mocha Mousse #8B4513
- **Accent:** Orange #FF6B35, Terracotta #E07A5F
- **Neutrals:** Warm Beige #F5F5DC, Cream #FEFEFE

## Features
✅ Sticky Video Player (folgt beim Scrollen)
✅ Live Portal Feed Simulation (mit Pulsing Indicators)
✅ Community Stats Dashboard (Animated Counters visual)
✅ Warm Organic Color Palette (2025 Trend)
✅ Rounded Corners (20px) für sanftes Design
✅ Warm Shadows (mit Mocha-Tint)
✅ Gradient Backgrounds (subtil)
✅ Interactive Live Cards

## Video Setup
**Wichtig:** Platzieren Sie Ihr Video hier:
```
./videos/prevideo-culturestream.mp4
```

### Sticky Video Funktion:
- Video startet normal in dedizierter Section
- Beim Scrollen nach unten wird es zum Mini-Player (rechts unten)
- Sync zwischen Haupt-Video und Mini-Player
- Buttons: Vergrößern (zurück zur Section) & Schließen

## Special Features

### Live Portal Feed
Simuliert Live-Streams von verschiedenen Portal-Standorten:
- Pulsing "LIVE" Badge
- Fake Viewer-Counts
- Hover-Effekte

### Community Stats
Zeigt Impact-Zahlen:
- 45+ Portale Weltweit
- 12K+ Aktive Nutzer
- 28 Länder Verbunden
- 850+ Events Pro Monat

### Sticky Video JavaScript
Automatische Erkennung wenn Video-Section aus Viewport scrollt
→ Mini-Player wird aktiviert
→ Playback-Position wird synchronisiert
