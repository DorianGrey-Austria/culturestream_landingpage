# Version 3: Minimal Canvas 🖼️

## Design-Konzept
Brutalist Minimalism mit extremem Whitespace und Bold Typography

## Farbpalette
- **Primary:** Black #000000
- **Accent:** Orange #FF6B35
- **Background:** White #FFFFFF

## Features
✅ Dedicated Video Section (Large Play Button)
✅ Extreme Whitespace (90-10 Principle STRIKT)
✅ Oversized Typography (120px+ Headlines)
✅ Monochrome Design mit Single Accent Color
✅ Full-Screen Quotes (One per Screen)
✅ Horizontal Scroll Team Section
✅ Split-Screen Layouts (50/50)
✅ Zero Border-Radius (Sharp Edges)
✅ Brutalist Aesthetic

## Video Setup
Video wird in dedizierter Section mit großem Play-Button angezeigt:
```
./videos/prevideo-culturestream.mp4
```

Klick auf Container startet Video → zeigt native Controls

## Design-Philosophie
- **90% Empty Space, 10% UI**
- **One Element per Screen** (wo möglich)
- **Bold > Subtle**
- **Sharp > Rounded**
- **Minimal > Decorative**

## Typography
- Headlines: 100-120px (Desktop)
- All UPPERCASE
- Inter for Sans-Serif
- Roboto Mono for Code/Mono

## No Animations
Brutalist Design = Minimal Animations
- Nur Hover-Farbwechsel
- Keine Transitions (außer minimal für Links)
- Focus auf Content, nicht Decoration

## Performance
- Ultra-lightweight (< 50KB CSS)
- No external dependencies (außer Fonts)
- Fast load time
- Minimal JavaScript
